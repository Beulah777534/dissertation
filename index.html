Two bytes separate the corpus.

Injected executable memory is ordinary on Windows XP. csrss.exe carries it on all nine non-malware images here. A region that opens with 4d 5a is not ordinary: those bytes are the DOS header of a Windows executable, so the region holds a mapped program rather than the fragments a runtime compiler leaves behind.
